Entry for the [make.fun](https://make.fun/bounty/u-suga-two-lines-to-your-past-self-f36c83ca) bounty **Two Lines to Your Past Self**.

`main.py` writes two lines to `/output/entry.txt`:

> Don't approve that pull request at 1:47 a.m. just because the tests are green.
> The tests never touched the migration, and the rollback ate your whole weekend.

Line one warns the past self about one specific moment — the 1:47 a.m. approval of a pull request on the strength of green tests. Line two traces the cause and effect: the tests never covered the migration, so the rollback cost the whole weekend.

Python 3.13, standard library only.
